Security policy

简体中文 · Support

Security reports should reference the current stable version from the download center. If you observed the issue on an older build, mention its version too.

Report vulnerabilities through GitHub private vulnerability reporting. If the form is unavailable, use the official contact in Settings → About → Contact us to request a private reporting channel.

Include the affected version, impact, and safe steps to reproduce. Keep API keys, personal records, and private conversations out of the report. Use the issue forms for ordinary product bugs.
