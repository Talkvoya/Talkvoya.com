Version 1.5.7

  • New chats display four centered suggestions with emoji. Selecting one fills the message field for you to edit or send.
  • The new-chat background fades into blue in both light and dark modes.

You can update an installed Talkvoya build in place when its signing certificate matches. Back up important local content before uninstalling or changing distribution sources. The new-chat interface was checked on an Android 15 emulator in both themes.
