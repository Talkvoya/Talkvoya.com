# Security policy

[简体中文](SECURITY.zh-CN.md) · [Support](SUPPORT.md)

Security reports should reference the current stable version from the [download center](TalkvoyaHarness/DOWNLOAD.en.md). If you observed the issue on an older build, mention its version too.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Talkvoya/Talkvoya.com/security/advisories/new). If the form is unavailable, use the official contact in **Settings → About → Contact us** to request a private reporting channel.

Include the affected version, impact, and safe steps to reproduce. Keep API keys, personal records, and private conversations out of the report. Use the [issue forms](https://github.com/Talkvoya/Talkvoya.com/issues/new/choose) for ordinary product bugs.
