# 安装与使用帮助

[产品介绍](README.zh-CN.md) · [下载](DOWNLOAD.md) · [English](HELP.en.md)

## 首次启动

1. 从[下载中心](DOWNLOAD.md)获取已签名 APK。需要 Android 8.0 或更新版本、ARM64 设备，并预留约 1.4 GB 安装运行环境。
2. 打开下载的 APK。若 Android 提示允许当前来源安装，查看提示后按需授权该来源。
3. 打开 Harness，阅读使用告知，等待本地运行环境初始化。
4. 在**设置**中添加自己的模型 API 密钥并选择支持的模型。新建对话，发送一条简短消息。
5. 手机操控和进度悬浮窗分别使用对应的 Android 权限。按需要从设置中开启。

## 常见问题

| 遇到的问题 | 排查方式 |
| --- | --- |
| APK 安装失败 | 核对 Android 版本、ARM64 兼容性、可用空间以及设备或组织是否限制侧载。 |
| 系统提示签名冲突 | 使用与已安装应用签名一致的 Talkvoya 安装包。卸载前请导出或备份重要内容，卸载会清除应用本地数据。 |
| 运行环境初始化卡住 | 检查可用空间和运行日志，并尝试在设置中重启引擎。 |
| 模型请求失败 | 检查服务商和模型选择、网络、密钥状态以及服务商的余额或限额。请妥善保管密钥。 |
| 手机操控不可用 | 核对无障碍服务、屏幕状态、敏感应用名单及设备限制。后台进度功能还需检查相应 Android 权限。 |
| 想切换界面语言 | 打开**设置 → 体验 → 切换语言**，选择简体中文或 English。 |
